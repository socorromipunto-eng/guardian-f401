# Guardian Command Registry

| ID | Command | Purpose |
|---:|---|---|
| `0x01` | `PING` | Verify communication |
| `0x02` | `DEVICE_INFO` | Read firmware and device metadata |
| `0x10` | `GET_STATUS` | Read runtime state |

Future command ranges will be reserved for:

- control
- configuration
- diagnostics
- events
- security
- firmware lifecycle
